Real FPGAs, one command away.

Manhattan Reasoning exists so that anyone, or any AI agent, can try a hardware idea on real silicon without owning a lab.

We run a rack of Lattice ECP5 boards behind the open-source toolchain, with a Python SDK, the mrg command line, and sandboxes where agents learn to design chips that are both correct and fast.

Boards you can reach from anywhere

Each board is a Lattice ECP5-85F running our base SoC. Your design builds in the cloud first; a board is only taken once the bitstream is ready, and it is wiped before anyone else gets it.

ECP5-85F
  1. FreeWaiting with the base SoC loaded.
  2. FlashingYour bitstream goes on.
  3. RunningYour Python reads and writes its registers.
  4. WipedA clear image goes on when you exit.
  5. Free againReady for the next design.

From design.py to a running board

One mrg run walks your design through the open hardware stack. Builds run in the cloud, so your laptop only waits.

  1. Synthesis Yosys turns your Amaranth or Verilog into a netlist.
  2. Place & route nextpnr fits it onto the ECP5 and checks timing.
  3. Bitstream ecppack packs the result for the chip.
  4. Flash The bitstream goes onto a free board.
  5. Run Your Python reads and writes the design’s registers.

A command line you can script

Install the SDK, sign in with GitHub, and run. Every step is a plain command, so an agent can drive it as easily as you can.

terminal
$
mrg login
Sign in with GitHub and store an API key.
mrg run design.py
Build, flash a free board, and run your entrypoint.
mrg status
Check whether a board is free right now.
mrg jobs, mrg logs
Your recent builds and their logs.
mrg cancel
Stop a build.
mrg synth, mrg pnr
Resource and timing reports on your own machine, no board needed.
client_sdk.py
import manhattan_reasoning_gym as mrg

class Regs(mrg.RegisterMap):
    DATA_IN  = 0x0004
    DATA_OUT = 0x0008

app = mrg.cloud.App(
    "my_design",
    design="design.py",
    registers=Regs,
)

@app.local_entrypoint()
def main():
    with app:  # programs the FPGA, releases on exit
        app.write(Regs.DATA_IN, 0xDEADBEEF)
        print(hex(app.read(Regs.DATA_OUT)))

Sandboxes for hardware agents

Isolated sandboxes to design, experiment and verify, then check the result on real silicon. We are building an RLVR environment with formal-methods researchers, with benchmarks to follow.

  • Runs locally, with no network and no keys
  • Reward signals you can verify
  • The same boards as everything else on this page
sandbox.py
import manhattan_reasoning_gym as mrg

sandbox = mrg.Sandbox(
    files=["examples/design.py", "examples/agent.py"],
)
result = sandbox.run("agent.py")  # no network, no keys

Why we are building this

The people who hold domain problems are largely absent from hardware work. Our research vision lays out how cloud FPGAs, an open toolchain and a competition for hardware SAT solvers can lower that barrier. We are a small team from a Barnard and Columbia research lab, led by Prof. Mark Santolucito.
